## 📂 Estructura del Repositorio

Los proyectos están organizados en tres niveles de dificultad:

- 🟢 **Básico**: Proyectos para asentar las bases de scripting, Linux, y herramientas fundamentales.
- 🟡 **Intermedio**: Proyectos que involucran automatización, CI/CD, contenedores y configuraciones más complejas.
- 🔴 **Avanzado**: Retos de arquitectura, orquestación, monitorización a gran escala y seguridad.
